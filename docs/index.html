Documentation

Everything you need to install Crooked Shelf, run your campaigns and extend it. The guides follow version 0.18 and are translated from the Italian originals.

InstallationDocker, without Docker, on a Raspberry Pi, online with HTTPS; settings, backups and security. User guideRoles and campaigns, pages and secrets, maps, timelines, roll tables, sessions, profile and administration. PluginsData-only plugins: themes, templates, calendars, languages, rules and links. How to write and install one. ClaudeConnect Claude to a campaign: the Claude Code plugin, the claude.ai connector and the token.
